# Публичная демонстрация CaspiFlow

Способ: изолированная production-сборка Next.js и FastAPI на MacBook, доступ через один HTTPS-домен Cloudflare Quick Tunnel. Это временная публикация для проверки, не перенос приложения в независимый облачный хостинг. Платные услуги не подключаются.

## Изоляция и запуск

```bash
backend/.venv/bin/python scripts/public_demo.py start
backend/.venv/bin/python scripts/public_demo.py status
backend/.venv/bin/python scripts/public_demo.py stop
```

`start` собирает текущий Git HEAD в `.runtime/public-demo/releases/<sha>` через `git archive` (только отслеживаемые файлы), устанавливает frontend по package-lock и делает production build. Используется установленный `backend/.venv` с зависимостями из `backend/requirements.lock.txt`. Сначала создаётся HTTPS-туннель, затем его точный домен становится `APP_ORIGIN` обоих серверов. Проверяется JSON health FastAPI, Next gateway и самого публичного HTTPS-домена; hostname не считается готовым до внешнего HTTP 200 со `status=ok`. HTTPS проверяется с доверенными CA httpx/certifi, без отключения проверки сертификатов. Watchdog останавливает дочерние процессы при их отказе. `caffeinate -i` препятствует автоматическому сну при открытой крышке; закрытие крышки, выключение и потеря сети всё равно остановят доступность.

Нужен официальный `cloudflared` в `.runtime/tools/cloudflared`: [загрузки](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/). На этой машине установлен Darwin ARM64 2026.11.0 из релиза Cloudflare; SHA-256 архива проверен по digest GitHub: `8c2f90277ef06a6080bb40b964d33f09f1188102f8798f2e344174b6cf41accf`.

Порты отдельной копии: Next `127.0.0.1:3010`, FastAPI `127.0.0.1:8010`; публичен только Next через туннель. Эти loopback-адреса нужны только серверным процессам; браузер использует HTTPS-домен и относительные `/api/*`. CORS для стороннего origin не включается. Локальная версия 3000/8000, её `.env`, пароль и база не изменяются и не публикуются. Никакой каталог проекта не раздаётся как файловый сервер.

## База, ML, секреты

SQLite: `.runtime/public-demo/data/caspiflow.sqlite` на постоянном диске MacBook. При первом старте она создаётся пустой и заполняется только синтетическими грузами/обучающей историей из кода. Локальная рабочая база не копируется. Новые изменения сохраняются между перезапусками туннеля и приложения, пока не удалён этот каталог; это не облачный диск и не резервное копирование.

Random Forest обучается при старте на детерминированной истории новой базы, с прежним разделением и версией. Артефакт pickle с локальной машины не требуется. Прогноз погоды запрашивается backend напрямую у Open-Meteo; пропуски не заменяются синтетикой. Карта использует внешние OSM-тайлы с существующим схематичным fallback.

В `.runtime/public-demo/secrets.json` создаются новые сервисный ключ и scrypt-хеш. Отдельный production-пароль находится только в `.runtime/public-demo/admin-password.txt` (0600); каталог 0700. Не отправляйте пароль в чат и не коммитьте эти файлы. Секреты передаются только runtime-процессам, без `NEXT_PUBLIC_*` и аргументов командной строки. Для просмотра пароля используйте локальный редактор.

Админка требует серверной сессии; cookie HttpOnly, SameSite=Strict, Secure при HTTPS. Для POST/PUT gateway проверяет точный `Origin`, ключ FastAPI доступен только серверу. Пять неправильных входов за пять минут блокируют последующие попытки. Публичных тестовых учётных данных нет. Перезапуск FastAPI отзывает сессии. Таможня остаётся предварительной локальной демо-заявкой без юридической силы; вводите только демонстрационные сведения.

## Перезапуск и ограничения

Для обновления: закоммитьте изменения, выполните `stop`, затем `start`. Секреты и SQLite сохранятся, но Quick Tunnel выдаст **новый домен**, который автоматически применится к Origin/cookie-настройкам. Актуальная ссылка и SHA — `.runtime/public-demo/deployment.json`; логи — соседние `*.log`, каталог приватный и игнорируется Git. Старый URL после остановки не обещается.

[Ограничения Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): нет SLA, URL временный, максимум 200 одновременных запросов, SSE не поддерживается. CaspiFlow не использует SSE. Отдельного sleep бесплатного backend-хостинга нет: backend находится на Mac, но сам Mac/интернет/процесс могут остановиться. Для независимого круглосуточного размещения нужны доступ к хостингу/серверу и постоянный диск либо перенос БД; это не настроено данным туннелем.

## Проверка публичного URL

После запуска проверяется фактический HTTPS-адрес, а не localhost. Итог и актуальный адрес будут зафиксированы в `PUBLIC_VERIFICATION.md` после реальных проверок.

Актуальная проверенная публичная ссылка, HTTP-статусы и 8 браузерных проверок: [PUBLIC_VERIFICATION.md](PUBLIC_VERIFICATION.md). Повтор:

```bash
CASPIFLOW_PUBLIC_URL=<актуальный-https-origin> npm --prefix frontend run test:e2e -- --config playwright.public.config.ts
```
