# Проверка CaspiFlow

Проверено 12 ноября 2026 на macOS ARM64 в установленном локальном Chromium 158.0.8127.18 через Playwright 1.65.0. Доступ к браузеру работает без ограничений. Мобильная версия проверяется эмуляцией Chromium, не физическим iPhone или Safari.

## Охват

Приложение одностраничное: проверены все пять разделов бокового меню, ссылка логотипа доступна на `/`. Восемь браузерных сценариев выполняются в двух конфигурациях: desktop 1440×1000 и mobile 390×664 с touch-эмуляцией. Дополнительно адаптивность проверена на ширинах 320, 390, 768, 1024, 1280 и 1440 px.

- Навигация по разделам, выбор всех четырёх грузов, поиск по номеру, названию и отправителю, пустой результат поиска.
- Все 12 сочетаний груз/маршрут: отображаемая задержка и полное время сверены с API; CO₂ независимо рассчитан по массе, расстояниям и коэффициентам транспорта. Общий CO₂ сверён с суммой по грузам.
- Шторм: кнопка 80%, ползунок 100%, пересчёт задержки, отображение штормовой зоны на карте, смена самого быстрого маршрута и сброс к штилю. Для CF-2026-0841 задержка прямого маршрута возрастает с 14.9 до 44.4 ч. При шторме 100% сухопутный маршрут быстрее прямого: 94.1 против 102.4 ч.
- Карта: реальные тайлы OpenStreetMap, карточки всех семи портов, масштабирование, перемещение, выбор груза через маркер, изменение геометрии выбранного маршрута.
- Таможня: браузерная валидация кода ТН ВЭД и стоимости, отображение ошибки API, настоящая подача заявки через Next.js в FastAPI и SQLite, повторное открытие квитанции после перезагрузки страницы, SHA-256 и закрытие окна. Ошибка API имитируется только в отдельном шаге; успешная подача выполняется без подмены.
- Клавиатура: начальный фокус в модальном окне, удержание фокуса при Tab, закрытие Escape и возврат фокуса на кнопку.
- Недоступность dashboard: сообщение ошибки, кнопка повтора, восстановление загрузки.
- Отсутствие горизонтального переполнения, ошибок JavaScript и ошибок консоли при обычной загрузке. Тайлы дожидаются полной загрузки перед основными скриншотами.

## Исправления

1. У кнопок бокового меню пропадали доступные названия после скрытия текста на мобильном экране. Добавлены постоянные `aria-label`, подсказки `title` и состояние текущего раздела `aria-current`.
2. Таможенное окно не переводило фокус внутрь, позволяло Tab уйти на фон и не закрывалось Escape. Добавлены начальный фокус, ограничение переходов Tab/Shift+Tab, закрытие Escape и восстановление фокуса. Во время отправки Escape не прерывает запрос. Фоновая прокрутка блокируется на время открытия окна.
3. Добавлена видимая индикация клавиатурного фокуса у кнопок, ссылок и полей.

В ходе первого полного прогона исправлен также сам тест перемещения карты: Leaflet перемещает слой CSS-трансформацией, поэтому проверяется изменение положения слоя, а не SVG-координат. Проверка закрытия popup ожидает завершения анимации.

## Результат

- Playwright: 16/16 после исправлений на dev-сервере; 16/16 в повторном полном прогоне на production-сборке.
- Backend pytest: 2/2, включая валидацию API, защиту ключом, идемпотентность, конфликт заявки, сохранение, шторм, CO₂ и метрики ML. Эти тесты используют временную SQLite.
- `npm run build` и `npm run typecheck` проходят.
- Существующие демо-заявки сохранены. Браузерные тесты удаляют только собственную заявку с инвойсом `INV-PLAYWRIGHT` по полученному ID.

## Границы проверки

Прогнозы и CO₂ проверены на демонстрационных данных. Проверка не подтверждает точность ML на реальных перевозках или сертификацию расчёта CO₂. Тайлы требуют доступа к OpenStreetMap. Backend-тесты выводят предупреждение Starlette о будущей миграции с httpx на httpx2; на результат тестов это не влияет.
