# Демонстрация CaspiFlow за четыре минуты

Цель — показать работающий inference и осознанное решение логиста по кейсу 2. Речь рассчитана примерно на 4 минуты с действиями, не на чтение всех подписей интерфейса.

## Перед выходом

1. Закрыть старые запуски CaspiFlow, из корня выполнить `./scripts/demo.sh`. Дождаться Ready и открыть http://127.0.0.1:3000. Если серверы уже запущены и проверены, повторно запускать не нужно.
2. Убедиться, что показаны четыре груза, карта и «Спокойное море», нагрузка — «Из данных маршрута». Масштаб браузера 100%, окно около 1440 px. Открыть отдельную вкладку с мобильным скриншотом как резерв.
3. Выбрать CF-2026-0841. При штиле его прямая задержка 19.8 ч, полное время 77.8 ч. Подготовить груз без заявки для шага таможни; если для 0841 заявка уже есть, использовать другой груз без заявки. Существующие записи не удалять.
4. Проверить интернет для OSM. При отсутствии тайлов схема маршрутов работает локально и показывает уведомление. Резервные кадры — `docs/screenshots/`, а не поддельная «живая» карта.
5. Не открывать `.env` и не выводить сервисный ключ на проектор. Цифры ниже относятся к версии `dd6d5aa09398`, сверить `/api/model` при изменении модели.

## 0:00–0:35 — задача логиста

**Действие:** показать верх экрана и выбрать CF-2026-0841 в списке или на карте.

**Речь:** «CaspiFlow — предиктивный цифровой двойник каспийского звена Север–Юг. Проблема — не просто найти груз на карте, а заранее понять, где сорвётся стыковка и какой путь выбрать. В одном окне видны прогноз, ETA, углеродный след и предварительная заявка. Все грузы, позиции и погода здесь демонстрационные».

## 0:35–1:35 — погода меняет решение

**Действие:** нажать «Симулировать шторм» (пресет 80%), затем довести ползунок до 100%. Показать оранжевые опасные морские участки, перейти к «До и после сценария».

**Речь:** «Это сценарий, а не метеопрогноз. Backend действительно передаёт новые погодные признаки в обученную модель. На прямом пути задержка выросла с 19.8 до 43.5 часа, ETA сдвинулось на 23.7 часа. Западный сухопутный вариант теперь быстрее: 92.9 против 101.5 часа».

**Действие:** нажать «Показать быстрый маршрут».

**Речь:** «Смотрим альтернативу, не перенаправляем реальный груз. Выигрыш по времени — 8.6 часа, но выбросы выше: 2358 против 668 кг CO₂. Логист видит цену решения в двух измерениях».

## 1:35–2:25 — ИИ с объяснениями

**Действие:** нажать «ML-аналитика» в боковом меню. Показать метрики, полосы и текущие входы.

**Речь:** «Random Forest обучен на 1440 синтетических рейсах, 480 отдельных использованы для калибровки диапазона и ещё 480 — для теста. MAE 2.97 часа против 6.90 у медианного baseline, RMSE 3.72, R² 0.802. Это не доказательство точности на реальном грузопотоке. Полосы показывают permutation importance — насколько портится качество при перемешивании фактора. Это глобальная важность, а не сумма причин задержки одного груза. Рядом — реальные входы его прогноза. Покрытие диапазона на тесте 86.67%, а не обещание прибытия».

Если спрашивают про нагрузку, показать выпадающий сценарий 30% и 99%, дождаться ответа; полный прогон можно оставить для вопросов.

## 2:25–3:25 — предварительное оформление

**Действие:** нажать «Цифровая таможня», при необходимости выбрать подготовленный груз без заявки; нажать «Подать заявку». Использовать вымышленные значения по умолчанию, сохранить. Открыть «Посмотреть».

**Речь:** «Кейс допускает цифровой коридор через защищённый API. Ключ находится только между сервисами. Backend проверяет поля и сохраняет заявку в SQLite; повтор той же заявки не создаёт дубликат. Результат явно называется демо-проверкой, без юридической силы. Связи с государственными таможенными системами нет, отпечаток SHA-256 не выдаём за электронную подпись».

**Действие:** закрыть окно, перезагрузить страницу, выбрать тот же груз и открыть квитанцию. Убедиться, что ID сохранился. При нехватке времени показать перезагрузку только по вопросу жюри.

## 3:25–4:00 — завершение и пилот

**Действие:** при необходимости нажать «Сбросить сценарий», вернуть CF-2026-0841; показать мобильный кадр и папку отчётов.

**Речь:** «Это работающий прототип: прогноз, маршрут, CO₂ и заявка связаны через API и проверены автоматическими тестами. Следующий шаг — пилот с историей оператора, AIS и погодой, независимая временная проверка качества и таможенная песочница. Мы готовы показать код, метрики и результаты тестов».

## Если что-то пошло не так

- Backend недоступен: интерфейс показывает ошибку и повтор; объяснить состояние, восстановить локальный запуск. Не называть старые данные новым сценарием.
- Нет тайлов: показать локальную схему. ML, заявки и сравнение не зависят от внешнего API.
- Все заявки уже поданы: показать сохранённую квитанцию и идемпотентность из тестов, не удалять записи на сцене.
- На вопрос про точное ETA: это расчёт от демонстрационного снимка отправления и полных часов пути; расписания и фактическая переотправка не подключены.
