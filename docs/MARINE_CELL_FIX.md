# Восстановление прогноза «Прямой Каспий»

12 ноября 2026. Причина подтверждена двумя реальными запросами Marine API с одинаковыми координатами 39.7, 49.2, полем `wave_height`, горизонтом 72 часа и временем UTC. Отличался только `cell_selection`:

| Выбор | HTTP | Координаты возвращённой ячейки | Числовых часов волн |
|---|---:|---|---:|
| nearest | 200 | 39.708336, 49.208344 | 0/72: все null |
| sea | 200 | 39.625, 49.375015 | 72/72 |

В исходном коде `nearest` применялся к обоим источникам. Ближайшая ячейка в этой точке не давала морских значений. Отсутствие волн делало окно прямого маршрута неполным, поэтому ML-задержка, ETA и общая стоимость корректно оставались неизвестными. Это не ошибка рисования и не свидетельство отсутствия морского прогноза для всего Каспия.

## Исправление

Для волн явно используется `cell_selection=sea`, для ветра сохранён `nearest`. [Документация Marine API](https://open-meteo.com/en/docs/marine-weather-api) описывает выбор морской ячейки этим параметром. Координаты маршрута не меняются, искусственные волны не создаются.

Расстояние от точки маршрута до возвращённой морской ячейки вычисляется по формуле гаверсинусов. Для южной точки оно составило 17.15 км. API возвращает выбранные координаты, расстояние, режим выбора и пояснение; интерфейс показывает, что это пространственное приближение модельного прогноза, а не измерение в точке груза.

Установлено ограничение **25 км**: более удалённая морская ячейка отклоняется с причиной, её значения не используются. Это консервативное демонстрационное ограничение приложения, не подтверждённая навигационная точность модели. Другие точки пакета сохраняются. Null, отказы источника и выход за временной горизонт по-прежнему не заполняются нулями или синтетикой; ветровой график работает независимо.

## Реальная проверка

[HTTP-сравнение и результат API CaspiFlow](marine_cell_probe.json) содержат время получения, статусы, координаты и доступность каждой точки. После исправления на всех шести морских точках получено 72 часа ветра и волн, на сухопутной — 72 часа ветра; волны там неприменимы. Дистанции морских ячеек: 3.42, 2.86, 17.15, 5.75, 1.17 и 3.78 км.

В сохранённом ответе для первого груза прямой маршрут вновь получил `RandomForestRegressor.predict`, задержку 19.9 ч и ETA `2026-11-16T01:54:00+00:00`. Это снимок изменяющегося прогноза, не константы приложения. Методика и версия ML не менялись.

Добавлены backend-тесты выбора морской ячейки, маркировки пространственного приближения, отклонения удалённой ячейки без потери других точек и сохранения null. Playwright проверяет живой южный график волн/индекса, пояснение и наличие ML-задержки, ETA и стоимости прямого маршрута для каждого груза на desktop/mobile. Прежние тесты частичного отсутствия волн сохранены.
