# Итоговый отчёт готовности CaspiFlow

Дата: 12 ноября 2026. CaspiFlow доработан в существующем проекте Next.js / FastAPI / SQLite / Python ML. Исходный документ кейса 2 найден и проверен; соответствие трём результатам MVP описано в [CASE_REQUIREMENTS.md](CASE_REQUIREMENTS.md). Система готова к локальной демонстрации. Публичная промышленная эксплуатация требует следующего этапа интеграций и защиты.

## Сохранение исходного состояния

До крупных правок создан локальный Git-репозиторий и контрольный коммит `ea91948` — рабочий исходный CaspiFlow. `.env`, база SQLite, окружения зависимостей и `.runtime` исключены из Git. Публикация в удалённый репозиторий не выполнялась. Существующие грузы и заявки сохранены; тестовые декларации удаляются только по собственным ID.

Уровень диапазона номинально 90%; он не подменяет наблюдаемое 86.67%. Прежний MAE 2.03 ч не переносится на новую модель: изменены объём train, отдельная калибровка и монотонные ограничения. Ветер, волна и загрузка теперь не могут уменьшить задержку при прочих равных. Синтетические метрики не подтверждают промышленное качество.

Живой `/api/model` сравнивается целиком с [ml_metrics.json](ml_metrics.json). Подробная методика, ограничения, формулы и воспроизведение — в [ML_REPORT.md](ML_REPORT.md).

Для CF-2026-0841 шторм 100% увеличивает прямую задержку 19.8 → 43.5 ч и сдвигает ETA на 23.7 ч. Прямой путь занимает 101.5 ч, западный — 92.9 ч; разница 8.6 ч. CO₂ 668 против 2358 кг: быстрый вариант в этом сценарии добавляет 1690 кг. Выбор альтернативы не изменяет сохранённый маршрут груза.

## Финальные проверки

Итоговый запуск завершён: **26/26 Chromium-проверок, 12/12 backend-тестов, production build, TypeScript и git diff --check прошли**. Подробные результаты зафиксированы в [VERIFICATION.md](VERIFICATION.md). Набор содержит 26 Chromium-проверок (13 сценариев × desktop/mobile) и 12 backend-тестов. Встроенные браузерные интеграционные проверки проходят через настоящий Next.js gateway и FastAPI; успешная подача заявки не подменяется mock. Отдельные шаги с ошибкой API и отсутствием тайлов намеренно имитируют сбой.

```bash
# Из корня; для запуска обоих сервисов на собранной версии
./scripts/demo.sh

# В другом терминале
backend/.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend run typecheck
npm --prefix frontend run test:e2e
backend/.venv/bin/python scripts/ml_audit.py
git diff --check
```

`demo.sh` сам запускает `npm --prefix frontend run build`. Браузерные тесты рассчитаны на loopback 3000/8000 и требуют хотя бы один груз без заявки; они удаляют только созданную ими декларацию. Backend pytest использует временную SQLite. Для параллельной разработки отдельную базу можно задать через CASPIFLOW_DB_PATH; нельзя направлять очистку браузерных тестов в одну базу, а сервер в другую.

## Границы готовности

Работает локальный MVP на MacBook с установленным Chromium. Проверка мобильной версии — эмуляция Chromium, не Safari на реальном iPhone. Предсказания, грузопоток, погода и нагрузки синтетические. Карта показывает snapshot, геометрия путей условная, ETA не использует реальные расписания. CO₂ — демонстрационная оценка, не сертифицированная ESG-метрика. Погодный риск на карте — правило сценария, не разрешение или запрет навигации. Таможенная заявка не имеет юридической силы; государственные интеграции не подключены.

Graph DB, полный транспортный граф, AIS/GPS, TOS, погода, таможенная песочница, пользовательские роли, TLS, rate limiting, мониторинг и промышленная БД — следующий этап. Сервисный ключ не заменяет пользовательскую авторизацию. Платные сервисы не подключались, секреты не публиковались, публичный deployment не выполнялся.
