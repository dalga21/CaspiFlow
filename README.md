# CaspiFlow

Демонстрационный MVP кейса №2 Smart Caspian Transit: цифровой двойник каспийского звена МТК «Север–Юг». Next.js + Tailwind CSS, FastAPI + SQLite, Python / scikit-learn.

## Запуск

В текущем окружении зависимости уже установлены, Node.js 22 находится в `.runtime/node-bin`.

```bash
./scripts/dev.sh
```

Приложение: http://localhost:3000 · API: http://127.0.0.1:8000 · Swagger: http://127.0.0.1:8000/docs

Скрипт запускает оба сервиса на loopback и создаёт `.env` с случайным сервисным ключом, если файла нет. Ctrl+C останавливает сервисы. Если сервер уже работает, повторный запуск не нужен. Ключ не должен попадать в Git или браузер. Для production локальный `.env` нужно заменить хранилищем секретов.

На другом компьютере: установите Node.js ≥22 и Python ≥3.12, затем:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.lock.txt
cd frontend
npm ci
cd ..
./scripts/dev.sh
```

## Готовность к финалу

Для репетиции на production-сборке остановите старые серверы и выполните:

```bash
./scripts/demo.sh
```

Скрипт проверяет порты, собирает существующий frontend, запускает FastAPI, дожидается готовности и запускает Next.js start. Секрет создаётся локально при отсутствии `.env`; публичная публикация не выполняется. Сервисы слушают только loopback. Ctrl+C останавливает их.

## Погода, экономика и администратор

«Ручная симуляция» сохраняет прежний ползунок. «Автопрогноз» получает 72 почасовые точки Open-Meteo, учитывает плановые окна морских участков, показывает источники, пропуски, предупреждения и графики. Прогноз задержки получает прежняя ML-модель; при недостатке погоды прогноз и ETA не подставляются из синтетики.

Экономика использует массу, километры, ML-задержку и настраиваемые демонстрационные тарифы USD. Рекомендация сравнивает время, стоимость и CO₂ по настраиваемым весам. Пропуски и выход за диапазон обучения делают её условной.

`/admin` защищён серверной проверкой пароля и сессией. Там доступны грузы/статусы, заявки, пороги, тарифы и журнал. Для собственного пароля выполните:

```bash
backend/.venv/bin/python scripts/configure_admin.py
```

В текущем окружении случайный локальный пароль сохранён только в `.runtime/admin-credentials.txt` (0600). Не публикуйте этот файл. Хеш — в `.env`; после смены пароля перезапустите серверы. Публичных учётных данных по умолчанию нет.

Диагностика графиков, HTTP-статусы, частичные данные и явный повтор: [WEATHER_GRAPH_FIX.md](docs/WEATHER_GRAPH_FIX.md).

Методика погоды, допущения прохождения, индекса и рекомендаций: [WEATHER_AND_OPERATIONS.md](docs/WEATHER_AND_OPERATIONS.md).

## Сценарий демонстрации

1. Выберите груз в списке или нажмите маркер на карте. Порты имеют всплывающие карточки; карту можно перемещать и масштабировать кнопками или двойным нажатием.
2. Сравните время и CO₂ трёх маршрутов. Нажатие карточки подсвечивает путь и обновляет расчёты цифрового двойника. Это просмотр варианта, груз не перенаправляется.
3. Нажмите «Симулировать шторм» и доведите интенсивность до 100%. Backend заново вызывает ML-модель для всех вариантов. Для первого груза сухопутный маршрут становится быстрее. Изучите «До и после сценария»: задержки, ETA, погодный риск и компромисс с CO₂. Выпадающий список позволяет отдельно изменить базовую загрузку узлов. «Сбросить сценарий» возвращает и погоду, и нагрузку.
4. Нажмите «Подать заявку», заполните демонстрационные реквизиты и сохраните. После перезапуска статус остаётся в SQLite. Повтор одинаковой заявки возвращает тот же ID, изменение уже поданной заявки возвращает 409.
5. Изучите «Почему ИИ дал такой прогноз?»: MAE, RMSE, R², медианный baseline, permutation importance и реальные входы выбранного прогноза. Важность глобальная и не является вкладом в отдельную задержку.

## Проверки

```bash
backend/.venv/bin/python -m pytest backend/tests -q
export PATH="$PWD/.runtime/node-bin:$PATH"
cd frontend
npm run build
npm run typecheck
```

Backend-тесты используют отдельную временную SQLite: защищённый API, валидация, идемпотентность, сохранение заявки, расчёт CO₂, влияние шторма, смена быстрейшего маршрута и метрики ML.

Браузерные проверки используют исходные четыре демо-груза и локальный закрытый файл пароля администратора (после собственной настройки пароля задайте CASPIFLOW_ADMIN_CREDENTIALS_PATH к закрытому файлу для тестов). Браузерные проверки в локальном Chromium (сначала запустите `./scripts/dev.sh` в другом терминале):

```bash
npm --prefix frontend run test:e2e
```

Playwright запускает 46 проверок: 23 сценария на десктопе и в мобильной эмуляции. Проверяются навигация, поиск и выбор грузов, три маршрута, прогнозы, CO₂, шторм, карта, таможенная форма и клавиатура, ошибки API и адаптивность. Тест подачи заявки требует хотя бы один груз без заявки; созданная тестом заявка удаляется по своему ID, существующие заявки сохраняются. Не запускайте параллельно несколько копий набора против одной базы.

Скриншоты: `docs/screenshots/`. HTML-отчёт и трассировки ошибок: `.runtime/playwright-report/` и `.runtime/playwright-results/`. Для повторной установки локального Chromium: `npm --prefix frontend run playwright:install`.

Для воспроизводимого ML-аудита и JSON с фактическими метриками:

```bash
backend/.venv/bin/python scripts/ml_audit.py
```

## Ограничения

Позиции, исходные грузы и обучающая история синтетические. Погода ручного режима синтетическая; автоматического — прогноз Open-Meteo с явными пропусками. Отслеживание показывает сохранённый снимок, без GPS/AIS и realtime. ML обучена на 1440 синтетических рейсах, диапазон откалиброван на 480, качество проверяется на отдельных 480; результат не подтверждает точность на реальных перевозках. Диапазон использует отдельную синтетическую калибровку; фактическое покрытие теста показано в UI. CO₂ использует демонстрационные коэффициенты. Геометрия и расстояния маршрутов схематичны; альтернативы заданы заранее. Тайлы OpenStreetMap требуют интернета; под ними есть локальный схематичный контур Каспия. Предварительное оформление — локальная демо-заявка, без связи с таможней и юридической силы.

API-key защищает взаимодействие сервисов. Администратор защищён серверной сессией; публичный логистический демоэкран пока без пользовательских ролей. Для публичного размещения нужны авторизация/роли, TLS, rate limiting и управление секретами. Не открывайте dev-серверы в интернет.

План, архитектура и следующий этап: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Восстановление морского прогноза прямого маршрута и выбор ячейки Open-Meteo: [MARINE_CELL_FIX.md](docs/MARINE_CELL_FIX.md).
